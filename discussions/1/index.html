What do you think of the new site?

So, here it is…the all new Session.

I know it’s been a long time coming - I hope I didn’t get anybody’s hopes up too early by announcing the new site all those months ago.

Well, I hope it was worth the wait. I’ve tried to make it as easy to use as possible.

I wonder if there’s anybody who remembers The Session’s humble beginnings? The site started as a small collection of tunes on a free host. Later, the site moved to my own web space. I also started added things like the searchable tune archive, the mailing list and the ability to post comments on the tunes.

But as the site and the mailing list grew, I realised two things. I was running out of tunes and there was a lot of people out there who had tunes to offer.

That’s when I started planning this redesign. Seeing as I was going to let people submit tunes, I thought why not recordings, links and discussions too?

I hope you don’t mind having to use a Username and Password to log on to the site’s best features. It’s the easiest way to keep track of who submits what.

I urge everyone to make use of the Tunebook feature. When you find a tune you like, you can put it in your online tunebook. When you’ve got a decent-sized tunebook, you can sort it by name, tune type or key and download an ABC file to your hard drive with all your tunes in it.

I’ve used some technology on the site which means it’s going to look much snazzier in newer browsers (Internet Explorer 5, Netscape 6). You’ll still be able to see everything if you use an older browser (like Netscape 4), but it will look fairly dull.

So, now I want your feedback.

Is anybody having any technical difficulties?

Is everything fairly clear and easy to understand?

Does anybody have any suggestions for improvements?

A list of all the tunes

Just to answer Francis’s question:

To find a list of all the tunes (like on the old site), go to tunes, leave the search box blank but “all tunes” selected. The resultant search will show all the tunes on the site (in alphabetical order).

If you want to see all the jigs or all the reels, then again leave the search field blank but select “jigs” or “reels”.

↳ Posted by Bill Porter on June 7th, 2001.

Thanks for the suggestions

I’d like to address some points from the last few posts.

First of all, Will: a bulletin board for posting requests for specific tunes is a good idea. I had something like this on the old site.
I’d like to make it possible for more than one person to request the same tune and then have the request list ranked with the most requested tunes at the top of the list.
I’ll start working on this. I’ll need to decide if it should be its own seperate section or part of the tunes section.

Secondly, Bill: the sheetmusic is intended primarily for screen reading as opposed to printing. You say it’s “limiting to folks that print stuff out, copy it and collect it in a notebook”. Well, this is the whole idea behind the member’s tunebooks.
By collecting all the tunes you want into one file you can download, you’ve already got your book preformated. Of course, you’ll need some kind of ABC software to turn the tunes into sheetmusic for printing (see the “Links” section), but this way you have far more control over the final printed version.

I’ve designed the layout of the pages so that they really make sense when you’re surfing as opposed to printing. I kind of envisioned the tunebooks as I kind of take-away version of what’s served up on the website.

↳ Posted by Will Harmon on June 10th, 2001.

Key signatures

I’ve added Gminor to the list of key signatures. I’m aware that this list isn’t complete, but I don’t want the choice to be too overwhelming. That’s why the list contains the more common modes in Irish music.

I will add further key signatures by request. If anybody has a tune in a key signature that doesn’t appear in the list, let me know and I will then add it.

The same goes for tune types, as long they have consistent characteristics. For instance, I can’t add “O’Carolan composition” to the list of tune types because it doesn’t say anything about the meter of the tune.
