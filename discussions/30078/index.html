One thing that would be very helpful, but I don’t know if it’s technically possible, would be to make the search tune search function (the one where you type in a tune fragment) more “smart”. The thing is, there are several ways that different people play and write (ABC) what amounts to the same thing and the search function only recognises a match if you type in the precise thing that the person happened to write.

In a spot in a tune where a roll can happen, in a session you can have ten people playing together and it sounds like everyone is playing pretty much the same thing, it all blends together, but each person might write it differently in ABC: one might write a G roll (but there are different ways to write it), one might write GFG, one might write GAG, one might write a long G, and so on. Of the, how many? ten? twenty? different ways of writing in ABC what amounts to the same thing, you have to guess precisely when doing a search here.

I would think that there’s a way to make a tune search function that recognises all the different ways of notating what amounts to a G roll as the same thing.
