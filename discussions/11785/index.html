Re: Youtube question

I think you can do it, but it probably requires digging into the source file to get the id of the video file (YouTube files are Flash format - either .swf or .flv). Then you’d have to grab that file one way or another.

To do that, you could build a link to the direct URL and mail it to yourself or make an html page with it as a link. Then you could right-click on the URL and say “Save Target File As Source” or something like that, depending on your browser.

Or if you’re running Mac OSX, you could just use the ‘curl’ command and grab it directly.

I wouldn’t be surprised if people have put together little applications to do it for you. But I find it easier just to bookmark them and go back whenever I want to see them again.

Re: Youtube question

Anything you stream from YouTube (and many other websites) ends up in your browser cache as a fairly large file in the FLV format, usually several megabytes if it’s a video.

There aren’t really any signifant problems in retrieving YouTube videos from the browser cache in Firefox ver 2.0 (this is on a PC, not a Mac, so I can’t comment on that machine).

Useful points to remember:
1. Note: This bit of advice applies to ANY browser. Don’t close your browser until you’ve looked at the cache. This is because some PC setups will clear the cache as soon as you come out of the browser - and then there’s nothing to find.
2. The Firefox browser cache is usually hidden several levels down in the file system. For instance, on my computer it is at
“C:\Documents and Settings\”my name“\Local Settings\Application Data\Mozilla\Firefox\Profiles\”random characters“.default\Cache”.
If you want to find the Firefox cache on your PC I suggest a Windows search for “Cache”.
3. File names in the Firefox cache are 10 characters in length, the first 7 of which are random, and the last 3 being “d01” (on my system). There is no file extension, so, as I said, you’ve got to look for a very recent large file, usually several MB for a YouTube music video, drag it to your desktop (which removes it from the cache), rename it and give it the FLV extension.

If you use the Opera browser, as I do sometimes, the cache is easier to find. Unless you have specified otherwise in the setup it will be in “C:\Program Files\Opera\profile\cache4”. Again, the cache file name will be essentially random characters based on the computer’s internal clock, but will have an extension, usually .TMP and sometimes .FLV (which is convenient for identification). The same advice applies about not closing your browser and then dragging the file from the cache to the desktop and renaming it.

The Internet Explorer cache is fairly obvious. Unless you’ve specified otherwise it will be in the root folder of the C: drive as “Temporary Internet Files”. Again, just use common sense and observation to locate the streamed file.

The main reason I use the browser cache system for getting at streaming videos is because YouTube has a track record of frequently altering its system so as to make direct downloads difficult or impossible (perhaps for copyright reasons). Of course, the hackers respond, but then a game of catch-up ensues. The browser cache system, although slower, I’ve always found to be fool-proof.

Re: Youtube question

The temporary halting of a YouTube video as it is being streamed is due to a number of factors, such as -
1) the speed of your internet connection (if you’ve got fast broadband it’s always better),
2) how popular the file is (if everyone and his dog is trying to view it simultaneously then it’s bound to stutter),
3) generally, how busy YouTube’s servers are at that moment,
4) how busy the internet is at that time - such as businesses and colleges waking up and going on-line in the USA just when you (in Europe) are trying to download a file from YouTube (in the USA).
The halting of the video as it streams won’t affect the file being saved in the browser cache. When the streaming video finally ends (the video window greys out) then the file in cache will have reached its maximum size.
Viewing FLV files. There are several free applications available and easily downloadable from the internet. My favourite is VLC Media Player, which is easy to use but also has a large number of facilites, and FLVPlayer. It’s a good idea to have both available because, for some obscure reason (possibly connected with the codec the maker of the original video used) an FLV video from YouTube sometimes may not play on VLC but will on another player, or vice versa.
Generally, it’s not a good idea to convert an FLV file to another format, unless you have a good reason to do so, because there is usually a fall-off in the quality of the converted file. An application that is pretty good at doing a conversion from FLV to another format if you really need to do it, is “SUPER ©” - just google that to track it down.
