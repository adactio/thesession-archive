Re: Notation

In formalised ABC notation (i.e. the format understood by ABC software), the file header has a mandatory ‘L’ field, denoting the default note length. For notating Irish Trad tunes, this is usually set to L:1/8, meaning that any note without a number following it is an 1/8-note (quaver) - A2 is a 1/4-note (crotchet), A4 a 1/2-note (minim), A/2 a 1/16 (semiquaver) etc. The same system applies to rests (notated as “z”).

Re: Notation

Without computers I think ABC would have little advantage over any other type of notation but with computers it’s huge. I took the maid behind the bar from here and the screen shot of standard notation was 45.7 kB, the midi was 2.18 kB and the ABC is 296 bytes an mp3 or other actual recording of the tune would take up even more space. The formatting can be reduced for each of these probably to make them smaller but it’s still pretty obvious which takes up less space.

Space probably isn’t a huge issue because we’re just talking a few kB per tune. Other reasons why it’s good with computers is that going from ABC to sheet music or midi is a much easier than going the other way around. Computers recognize ASCII characters but you’ll have a lot more trouble trying to go from sheet music to ABC unless you made the sheet music on a computer and have the original file and not just a pdf or scan.

On top of space and ease of conversion to other types, searching tunes is a lot easier with ABC than it is sheet music. If you know how a tune goes and can play/sing even just a small part of it, typing the ABC into this website can easily find results of tunes that have that bit of melody in them. Posting sheet music you can still get the answer but you’re counting on other people to read your post, recognize the tune and respond, rather than just getting the tune name directly from the online database.

EDIT: My last thought on an advantage is that editing a tune in ABC simply requires a word processor, even MS Notepad is good enough. Editing a tune with sheet music or audio file would take special software.

Re: Notation

Even professional level software editing programs rely on some form of file format for the application to read. I defy anyone to read and edit those types of files directly though. ABC is somewhat simplistic and I’ve had users of “professional” software (Sibelius) diss ABC notation quite thoroughly because ABC isn’t at the level of their software. Too bad. The tunebook they have is in pdf format and was created with EasyABC. Without the abc code (and a good editor like EasyABC) which they eschewed the usage of, it can’t readily be re-created to add or delete tunes or correct errors.

ABC is just text which allows for changes in a file when necessary. When I was involved with the Tom Buchanan Scottish Tome project, I “extended” EasyABC’s code window using QuicKeys and unix shell scripts with the Terminal application on my Macintrash. Want a slurred triplet? No problem, I just hi-lighted the notes, hit a key and off it went. Same for adding note modifications for strathspeys and so on. Any word processor can handle the same tasks that I chose to automate (you would too faced with 652 pages of hand-written scores). It’s just easier when you can immediately see the rendered score on the screen and easily back out of a change that isn’t desired. Where ABC notation falls down flat on its face for the normal user is the audio playback via the internal midi functions like those found in EasyABC. Personally, I think the Mac has better sounding midi than Windows 7/10 (I’ve tried EasyABC under all of those) but the midi output is, well, offensive if you’re expecting something close to what you’d hear from a real instrument. I just use the playback to get the hang of the timing and the basic tune while I memorize it. If I get totally and irrevocably confused (it happens), I’ll refer to the ABC code to make certain I know what note is supposed to play and because I’m hopelessly inept sometimes and determining which note I’m playing when up the neck on my bouzouki, I’ll let the tuner tell me what I’m playing so I can correct myself. I suppose that’s a suitable approach when learning a tune but I certainly wouldn’t care to try it at a session.

There are a lot of positives to learning a good ABC editor and using it to ones advantage. Sight readers may pooh-pooh the thought of ABC but the difference between the legibility of a hand-written sheet of music can be pretty dramatic when there’s a clear pdf available that was generated from ABC code. An individual that only learns by ear need not refer to ABC midi playback unless the tune is simply unavailable in any audio format at which point, an ABC rendering may make it possible. Presumably, that individual would not be someone that can read music but there are so many variations on skill levels for everyone that it just really comes down to “use this tool if you want to”, if you don’t, don’t cast aspersions on it - it wouldn’t exist if there were no need for it.
