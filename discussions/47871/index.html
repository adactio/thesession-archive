New Client-side ABC-to-Notation Converter

With the demise of the mandolintab converter, I forked another abcjs based project and built this completely client-side open-source abc-to-notation converter.

This means the code runs entirely in your browser, does not call out to any other systems, you can even copy the whole project to your own system and run it just by opening the abctools.html file.

It can generate standard notation, note name tab, mandolin tab, guitar (standard and DADGAD) tab, as well as whistle tab. Also exports to PDF.

Perhaps others might find it useful:

http://michaeleskin.com/abctools/abctools.html

Works best on Chrome and Firefox.

Full source on my GitHub repo, feel free to fork it and modify it to your requirements!

https://github.com/seisiuneer/abctools

https://youtu.be/ixCHWD6PXsM

One note, this converter is limited to single tune transcriptions.

One could “massage” the ABC for a multi-tune set into a single ABC file and convert it, like this:

Start with two tunes:
X: 1
T: Allistrum’s
R: polka
C: Polka
M: 2/4
L: 1/8
K: Dmaj
|:FE ED/E/|FD D>E|FA de|dB BA|
FE ED/E/|FD D>E|FA dA| B2 BA:|
|:FA d>e|fe e2|d2 de|dB BA|
FA d>e|fe e2|d2 cA| B2 BA:]
X: 2
T: Ned Kelly’s
R: polka
C: Polka
M: 2/4
L: 1/8
K: Dmaj
|:F2 ED |FA A>B|AF ED|B2 BA|
F2 ED |FA d>c|BA FE|1 ED DE:|2 ED D2||
|:A2 d>f|ed d>B|Ad fd|e2 dB|
A2 d>f|ed d>B|BA FE|1 ED D2:|2 ED DE|]
Remove the headers on the second tune and stick in a %%center item for the titles:
X: 1
T: Allistrum’s/Ned Kelly’s
R: polka
M: 2/4
L: 1/8
K: Dmaj
%%center
%%center Allistrum’s
%%center
|:FE ED/E/|FD D>E|FA de|dB BA|
FE ED/E/|FD D>E|FA dA| B2 BA:|
|:FA d>e|fe e2|d2 de|dB BA|
FA d>e|fe e2|d2 cA| B2 BA:]
%%center
%%center Ned Kelly’s
|:F2 ED |FA A>B|AF ED|B2 BA|
F2 ED |FA d>c|BA FE|1 ED DE:|2 ED D2||
|:A2 d>f|ed d>B|Ad fd|e2 dB|
A2 d>f|ed d>B|BA FE|1 ED D2:|2 ED DE|]

Re: New Client-side ABC-to-Notation Converter

David50, regarding the transpose up and down operations, they are just done using text replacement in the ABC with some intelligence around the octaves.

The transposer doesn’t have any real idea about the key, so may not produce the expected result for some cases, for example Bmin transposed up will result in Cmin, not C#min.

This is fine for the common cases like taking a tune in A and shifting it to G, or G to A, D to G, Bmin to Amin, etc. That’s pretty much what’s its good for.

Re: New Client-side ABC-to-Notation Converter

Something like that. When you write ABC, you don’t have to specify F-sharp if the key is D, you just type an F. That makes doing any kind of actual operation on the notes themselves more challenging, if you really want to do this “right” you’d have to look at the keys, have tables and rules for the sharps and flats when doing semitone transpositions, etc.

That’s not my goal. I’m trying to make something that is useful for the 95%+ cases that are typically useful for traditional Irish music transcriptions, not a does-all-things-for-all-possible-use-cases converter. If someone needs something more advanced, I heartily recommend EasyABC.

For example, it was challenging when building the note name tablature to figure out whether to use sharp or flat symbols for the note names. That involved generating the music, going line by line and actually looking inside the rendered code SVG group for the key signature and seeing if it contained sharps or flat glyphs, then adapting the note names for that line based on what I found. Interesting puzzles!

For my client-side web-based ABC-to-notation transcription tool, I changed out the Javascript framework I was using for the PDF rasterization.

It’s now 10-100x faster generating PDF files for multiple tunes.

The original Javascript framework, html2canvas, would get slower and slower as the number of tunes being rendered increased.

The replacement Javascript framework, html-to-image, does not have that issue and renders each individual tune in the same time whether there are 3 or 30 tunes.

W:

Here’s how to use the new “Test Share URL” feature to create Home Screen tune set icons natively on an iOS device.

First launch the ABC Transcription Tool in mobile Safari by visiting:

http://michaeleskin.com/abctools/abctools.html

Enter some ABC into the text box or, as shown in demo, import a .ABC file from iCloud or other file storage location.

Once the music is rendered, click the “Advanced Controls” button.

This will show the Advanced Controls panel.

Next, click the “Generate Share URL” button to generate and show the share URL.

Finally, click the “Test Share URL” button, which will open the share URL in a new browser tab.

Once the new tab with the share link is open and the music is showing, go to the browser’s Share panel and click “Add to Home Screen”.

Enter a short name for your Home Screen button icon label. A tune or set name would be ideal.

The icon is created and added to your device’s Home Screen.

Clikcking the icon will launch the tool and fill in the saved tune set automatically.
