ABC Transcription Tools - October 2024 Updates

I’ve added a new box tablature style option to my ABC Transcription Tools that will allow you to create a new“Push/Draw” style tab for B/C and C#/D boxes.

This is in addition to my default tab style which uses numbers and characters to indicate row, button number, and bellows direction.

Since on these style boxes we mostly play on the inner row for traditional Irish music, I use the single quote after the button number to indicate the outside row.

Otherwise, if I followed the standard D/G style system where the inner row gets a single quote after the button number, nearly every single note would have a quote on it.

The tool can generate a complete standalone website for you from the ABC tunes in the editor without any coding required.

You may customize the title, subtitle, background color, and width and height of the player frame.

Additionally, you may optionally select a soundfont, melody, bass, and chord instruments and volumes to inject into each tune for use when the tune is played.

The website has a tune selector at the top, selecting a tune opens the tune in the ABC Transcription Tools player in the frame below the selector.

The tune will be displayed using the current notation or stringed instrument tablature setting selected at the time the website is generated.

You can take the resulting .html file, customize it if you want, run it locally, or host it on your own web hosting service.

Re: ABC Transcription Tools - October 2024 Updates

It’s on the “Generate Tunebook Website” dialog, where you actually specify the settings and then generate and save the site.

You can get there by adding a few tunes to the editor and then going to “More Tools”/“Export All Tunes”/“Generate Tunebook Website”

or by Shift-clicking the “Export PDF” button.

The frame size when exporting a responsive website adapts automatically to whether or not you’ve entered strings into the footer fields on the “Generate Tunebook Website” dialog.

Here’s the info info the User Guide:
https://michaeleskin.com/abctools/userguide.html#generate_website

Note that the website generation feature and the batch tune audio/graphics export features are only available on desktop browsers. While you can certainly consume a generated tunebook website on mobile, you have to create and save it on a desktop browser.

Re: ABC Transcription Tools - October 2024 Updates

To absolutely clear, the tool itself is designed to work primarily in portrait mode on mobile, with some very specific enhancements optionally available for landscape use on iPad. I don’t recommend using it in landscape on narrow aspect ratio mobile devices, it generally would not be a satisfactory experience.

I will not be doing any work on the tool to improve its use in landscape mode on mobile, and since the website generator simply hosts the tool inside an iframe, it will have exactly the same limitations.

This is why I suggest, if landscape use on very narrow aspect ratio mobile with optional playback is your top use case, a PDF with play links would be a much better, and really, the only truly workable solution.

I cannot solve all things for all imaginable scenarios. The source code for all of this is available on my GitHub repo, anyone is welcome to fork the repo, develop improvements, and then request they be integrated back into the tool through a pull request. All of the code for the website generator feature in the tool is in the file website_generator.js
