Re: ABC Transcription Tools May 2024 Features Update

I’ve added a lot more flexibility to the tool around defining custom boom-chick backup patterns, even allowing them to be changed on the fly in the middle of a tune.

This is done using a new

%%MIDI abctt:boomchick

command, which replaces the original

%abcjs_boomchick

annotation.

The original version would only allow setting the boom chick pattern for the entire tune.

The new version allows you to change the pattern “on-the-fly”.

If you were using the original %abcjs_boomchick annotation (now removed entirely, I honestly think very few people used this feature), the parameters are exactly the same. You will simply need to just change

%abcjs_boomchick
to
%%MIDI abctt:boomchick
in any tunes that used the previous annotation.

Re: ABC Transcription Tools May 2024 Features Update

I’ve changed the default timing of the automatic backup boom/chicks generated for ABC tunes that have chords, generally lengthening the booms and shortening the chicks.

The defaults are meter-adaptive.

The new default beat fractions for 6/8, 9/8, and 12/8 meters are 125% of the beat for the boom (these meters all have rests after the boom) and 40% of the beat for the chick.

For all other meters, the default beat fractions are 80% of the beat for the boom and 40% of the beat for the chick.

Previously they were set to 50% of the beat for both the boom and the chick.

There is nothing you need to do to get the improved backup, tunes with backup chords should just sound nicer now.

You can override the defaults using the:

%%MIDI abctt:boomchick_fraction beat_fraction
%%MIDI abctt:boom_fraction beat_fraction
%%MIDI abctt:chick_fraction beat_fraction

MIDI commands.

Full details on these commands are in the User Guide:

https://michaeleskin.com/abctools/userguide.html#custom_backup_beat_timing

Demo video comparing the old and new default boom/chick backup timings:

https://youtu.be/vDVH4_yizbQ

Re: ABC Transcription Tools May 2024 Features Update

More details on the defaults:

The default value for 6/8, 9/8, and 12/8 meters are 125% of the beat for the boom and 40% of the beat for the chick.

The default value for 4/4 is 80% of the beat for the boom and 40% of the beat for the chick.

The default value for 2/4 is 60% of the beat for the boom and 60% of the beat for the chick.

For all other meters, the defaults are 50% of the beat for the boom and 50% of the beat for the chick.

Pushed live some additional automatic backup-related changes, specifically there are cases with multiple chord changes in a measure where abcjs by default would substitute a chick instead of a boom during the chord transitions which to me always sounded a bit odd.

I’ve bypassed that logic and forced boom in these cases, which to my ear sound better having listened to probably thousands of tunes with the original solution.

I’ve run a few hundred tunes of all common styles through the code and they sound good to me.

Also updated the 3/4 meter boom and chick fractions. The default value for 3/4 is 75% of the beat for the boom and 50% of the beat for the chick.

Re: ABC Transcription Tools May 2024 Features Update

I’ve added support for playing strummed chords:

By default, chords are played as a block chord.

If you want to have the backup chords played in a strummed style, you can include the following annotation anywhere in the tune’s ABC:

%%MIDI abctt:strum_chords on

or

%%MIDI abctt:strum_chords true

This can be very effective when using a plucked string instrument as the chord MIDI program.

To turn strummed chords off, you can include the following annotation anywhere in the tune’s ABC:

%%MIDI abctt:strum_chords off
or
%%MIDI abctt:strum_chords false

To set the timing between the notes in the strum as a division of a eighth note, you can include the following annotation anywhere in the tune’s ABC:

%%MIDI abctt:strum_chords_divider divider_value

For example, to have the timing between the notes in the strum set to 1/10 of an eighth note, add the following to the tune:

%%MIDI abctt:strum_chords_divider 10
The default divider_value is 8.

Strumming enable and divider can also be changed mid-staff using inline MIDI directives:

[I:MIDI=abctt:strum_chords on]
[I:MIDI=abctt:strum_chords_divider 10]

To have the strummed chords ring longer, you can experiment with different values for the backup boom and chick timing fractions, for example:

%%MIDI abctt:boom_fraction 100
%%MIDI abctt:chick_fraction 100

These directives are private to this tool and will not work with other ABC players.

Demo video showing enabling and disabling strummed chords:

https://youtu.be/fe4qWSf1O-0

Demo video showing using the boom_fraction and chick_fraction to lengthen the backup:

https://youtu.be/tLyuoT2_XnI

Re: ABC Transcription Tools May 2024 Features Update

I’m surprised I never noticed this and also that nobody complained. :-)

You can now change the backup bass and chord programs and volumes on-the-fly in the middle of a tune.

Changing the melody instrument on-the-fly, the issue was limited to changing the bass and chord instruments and volumes.

Previously, having any of these style MIDI commands after they were set initially did nothing, now they work correctly (just picked random values for after the commands below, substitute whatever you want):

%%MIDI bassprog 38
%%MIDI chordprog 6
%%MIDI bassvol 32
%%MIDI chordvol 32

Their inline MIDI equivalents also now change the sound on-the-fly:

[I:=MIDI bassprog 38]
[I:=MIDI chordprog 6]
[I:=MIDI bassvol 32]
[I:=MIDI chordvol 32]

Just a reminder, you can mute the bass or chords using either:

%%MIDI bassprog mute
%%MIDI chordprog mute

or

%%MIDI bassvol 0
%%MIDI chordvol 0

or their inline MIDI equivalents:

[I:=MIDI bassprog mute]
[I:=MIDI chordprog mute]
[I:=MIDI bassvol 0]
[I:=MIDI chordvol 0]

Additionally, I fixed a long-standing bug with:

%%MIDI gchordoff

before the tune’s ABC.

It now works as you would expect, turning off the backup at the very start of the tune

Previously it did nothing unless present inside the actual tune ABC as a discrete or inline MIDI, didn’t work if it was present before the tune’s ABC notes.

%%MIDI gchordon

turns the backup back on.

These both have inline MIDI equivalents that can be used anywhere in a tune’s ABC:

[I:MIDI=gchordoff]
[I:MIDI=gchordon]

Re: ABC Transcription Tools May 2024 Features Update

Continuing with the cavalcade of backup feature enhancements, I’ve added the ability to very easily shift the backup bass or chords up one or two octaves using the following syntax, adding an optional octave=<value> after the bassprog or chordprog commands.

%%MIDI bassprog 38 octave=1
%%MIDI chordprog 0 octave=2

(where the 38 and 0 are arbitrary, replace with your choices)

This is a subset of the abcmidi extended bassprog and chordprog syntax, which also allows shifting the bass and chords down one or two octaves.

Unfortunately, the abcjs soundfont notes don’t go low enough to support that for the bassprog and in my testing, even if I allowed it just for the chordprog, it really didn’t sound useful, so I’m limiting the octave shifting to only in the positive direction.

Once the octave is set for the bass or chords in a tune, it will stay set until changed.

You can reset the octave using:

%%MIDI bassprog 38 octave=0
%%MIDI chordprog 0 octave=0

Again, the 38 and 0 are arbitrary, replace with your choices.

The inline versions also work:

[I:MIDI=bassprog 38 octave=1]
[I:MIDI=chordprog 0 octave=2]
[I:MIDI=bassprog 38 octave=0]
[I:MIDI=chordprog 0 octave=0]

You can change the octaves for the bass and chords anytime you want in a tune, either with a discrete %%MIDI directive or the inline equivalent.

You will then be notified that the page will be reloaded for the setting to take effect.

With this feature enabled, I find it most effective to use the iPad in landscape orientation.

At this time this feature is for iPad only and works on all three versions of the tool (Standard, Quick Editor, Offline-enabled).
