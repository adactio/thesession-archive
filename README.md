# The Session archive

This is a snapshot of the content on [The Session](https://thesession.org) for you to browse locally on your own machine.

You don’t need to set up a web server to view the pages. Click on `index.html` to open the home page and you can click around from there.

Each HTML file has been written to be self-contained. This means you could, for example, send someone one of these HTML pages as an email attachment.
